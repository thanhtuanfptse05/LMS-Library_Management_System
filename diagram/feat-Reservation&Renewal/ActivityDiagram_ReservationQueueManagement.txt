[Initial Node 1.1]
Actor: Librarian
Loại: Initial Node
Tên Action: Start Cancel Reservation Flow

Actor: Librarian
Loại: Manual Action
Tên Action: Select reservation record & click Cancel
Nội dung Action: Thủ thư chọn bản ghi đơn đặt trước trên bảng giao diện và bấm nút "Hủy".
Nối tới: Mũi tên đi tới [Manual Action 2.2].

[Manual Action 2.2]

Loại: Manual Action
Tên Action: Enter cancellation reason & submit request

Nối tới: Mũi tên đi tới [System Action Box 3.1].

[System Action Box 3.1]
Actor: System
Loại: System Action Box
Tên Action: Authenticate Librarian role & validate reason
Nội dung Action: Hệ thống kiểm tra phân quyền tài khoản Thủ thư (Librarian role) và kiểm tra lý do hủy (reason) có được nhập hay không.
Nối tới: Mũi tên đi tới [Decision Node 4.1].

[Decision Node 4.1]
Actor: System
Loại: Decision Node
Tên Action: Reason provided?
Nội dung Action: Kiểm tra Thủ thư có nhập lý do hủy hay để trống.

Nhánh [No (Không nhập lý do)]: rẽ tới [System Action Box 4.2].
Nhánh [Yes (Đã nhập lý do)]: rẽ tới [System Action Box 5.1].

[System Action Box 4.2]
Actor: System
Loại: System Action Box
Tên Action: Show validation error message "Reason is required"

[System Action Box 5.1]

[Decision Node 6.1]
Actor: System
Loại: Decision Node
Tên Action: Canceled reservation had ready-pickup spot? (queuePosition == 0)

Nhánh [No (queuePosition > 0)]: rẽ tới [System Action Box 8.1].
