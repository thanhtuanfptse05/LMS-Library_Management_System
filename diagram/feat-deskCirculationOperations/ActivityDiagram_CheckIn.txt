ACTIVITY DIAGRAM — UC-19: DESK CHECK-IN (NHẬN TRẢ SÁCH TẠI QUẦY)
Feature: F6 — Desk Circulation Operations
Version: 2.0 | Ngày cập nhật: 2026-08-02
Mô tả: Luồng hoạt động chi tiết cho nghiệp vụ Nhận trả sách tại quầy (Check-in), đã đồng bộ chính xác với kiến trúc Decouple F6/F13 và CodeGraph.
Actors: Librarian, LMS System, Email System
Business Rules áp dụng: BR-24, FR-001, FR-002, FR-003, FR-004, FR-006, FR-007, FR-F6-05, FR-37, FR-38, FR-39

========================================================================

[Initial Node 1.1]
Actor: Librarian
Loại: Initial Node
Tên Action: Start Check-In Flow
Nội dung Action: Điểm bắt đầu luồng Nhận trả sách tại quầy. Thủ thư truy cập trang Desk Dashboard và chọn chức năng "Nhận sách (Check-in)".
Nối tới: Mũi tên đi tới [Manual Action 2.1].

[Manual Action 2.1]
Actor: Librarian
Loại: Manual Action
Tên Action: Scan Barcode And Select Condition
Nội dung Action: Thủ thư quét Barcode trên bản sao sách và chọn tình trạng vật lý (condition): 'good' (nguyên vẹn), 'damaged' (hư hỏng), hoặc 'lost' (thất lạc). Nhấn "Xác nhận Nhận sách".
Nối tới: Mũi tên đi tới [System Action Box 3.1].

[System Action Box 3.1]
Actor: LMS System
Loại: System Action Box
Tên Action: Fast Validation & Trigger Lazy Sweeps
Nội dung Action: Kiểm tra condition thuộc whitelist {'good', 'damaged', 'lost'}. Thực thi Lazy Sweeps: ReservationExpirationProcessor.processExpiration() và OverdueProcessor.processOverdue().
Nối tới: Mũi tên đi tới [System Action Box 3.2].

[System Action Box 3.2]
Actor: LMS System
Loại: System Action Box
Tên Action: Query Book Copy By Barcode
Nội dung Action: Mở kết nối CSDL. Gọi BookCopyDAO.findByBarcode(conn, barcode) để tìm bản sao sách.
Nối tới: Mũi tên đi tới [Decision Node 4.1].

[Decision Node 4.1]
Actor: LMS System
Loại: Decision Node
Tên Action: Check Book Copy Validity & Status
Nội dung Action: Kiểm tra bản sao sách có tồn tại và đang ở trạng thái 'borrowed' hay không.
Nối tới:
Nhánh [BookCopy == null hoặc status != 'borrowed']: rẽ tới [System Action Box 4.2].
Nhánh [BookCopy hợp lệ & status == 'borrowed']: rẽ tới [System Action Box 5.1].

[System Action Box 4.2]
Actor: LMS System
Loại: System Action Box
Tên Action: Return Invalid Book Copy Error
Nội dung Action: Trả về lỗi: "Mã vạch không tồn tại hoặc bản sao sách không ở trạng thái 'borrowed'". Hiển thị trên Desk Dashboard.
Nối tới: Mũi tên đi tới [Final Node 20.1].

[System Action Box 5.1]
Actor: LMS System
Loại: System Action Box
Tên Action: Query Active Borrow Record & Calculate Overdue
Nội dung Action: Gọi BorrowRecordDAO.findActiveBorrowRecord(conn, bookCopyId) để lấy thông tin mượn (borrowRecordId, userId, bookId, endDate). Tính số ngày trễ = (NOW() - endDate).
Nối tới: Mũi tên đi tới [Decision Node 6.1].

[Decision Node 6.1]
Actor: LMS System
Loại: System Action Box
Tên Action: Check Active Borrow Record Existence
Nội dung Action: Kiểm tra có phiếu mượn đang hoạt động hay không.
Nối tới:
Nhánh [BorrowRecord == null]: rẽ tới [System Action Box 6.2].
Nhánh [BorrowRecord != null]: rẽ tới [System Action Box 7.1].

[System Action Box 6.2]
Actor: LMS System
Loại: System Action Box
Tên Action: Return Missing Borrow Record Error
Nội dung Action: Trả về lỗi: "Không tìm thấy bản ghi mượn đang active cho mã vạch này".
Nối tới: Mũi tên đi tới [Final Node 20.1].

[System Action Box 7.1]
Actor: LMS System
Loại: System Action Box
Tên Action: Open DB Transaction & Route Condition
Nội dung Action: Bắt đầu Transaction (conn.setAutoCommit(false)).
Nối tới: Mũi tên đi tới [Decision Node 7.2].

[Decision Node 7.2]
Actor: LMS System
Loại: Decision Node
Tên Action: Evaluate Condition Branch
Nội dung Action: Rẽ nhánh xử lý theo tình trạng sách do Thủ thư chọn.
Nối tới:
Nhánh [condition IN ('damaged', 'lost')]: rẽ tới [System Action Box 8.1].
Nhánh [condition == 'good']: rẽ tới [System Action Box 12.1].

====================================================================
NHÁNH A: SÁCH HƯ HỎNG HOẶC THẤT LẠC (DAMAGED / LOST) — DECOUPLED ARCHITECTURE (FR-001 -> FR-007)
====================================================================

[System Action Box 8.1]
Actor: LMS System
Loại: System Action Box
Tên Action: Update Borrow Record To Returned
Nội dung Action: Gọi BorrowRecordDAO.updateStatusToReturned(conn, borrowRecordId) — Cập nhật status = 'returned', returnedAt = NOW().
Nối tới: Mũi tên đi tới [System Action Box 8.2].

[System Action Box 8.2]
Actor: LMS System
Loại: System Action Box
Tên Action: Update Book Copy Status To Unavailable
Nội dung Action: Gọi BookCopyDAO.updateStatusToUnavailable(conn, bookCopyId, condition). Chuyển status = 'unavailable', lưu condition vật lý. KHÔNG giảm totalQuantity, KHÔNG xóa khỏi kho (chuyển F13 xử lý).
Nối tới: Mũi tên đi tới [System Action Box 8.3].

[System Action Box 8.3]
Actor: LMS System
Loại: System Action Box
Tên Action: Create Pending Book Copy Incident
Nội dung Action: Gọi BookCopyIncidentDAO.insertPendingFromCheckIn(conn, incident, borrowRecordId). Tạo bản ghi sự cố với status = 'pending', liên kết borrowRecordId để F13 xác minh và xử lý phạt đền bù sau. (Phạt quá hạn, nếu có, đã được OverdueProcessor xử lý).
Nối tới: Mũi tên đi tới [System Action Box 8.6].

[System Action Box 8.6]
Actor: LMS System
Loại: System Action Box
Tên Action: Insert Audit Log For Pending Incident
Nội dung Action: Gọi UserDAO.insertAuditLog(librarianId, 'CHECK_IN_INCIDENT_PENDING', ...). Ghi nhận nghi vấn thành công.
Nối tới: Mũi tên đi tới [System Action Box 19.1].

====================================================================
NHÁNH B: SÁCH NGUYÊN VẸN (GOOD) — FR-38, FR-F6-05
====================================================================

[System Action Box 12.1]
Actor: LMS System
Loại: System Action Box
Tên Action: Update Borrow Record To Returned (Good)
Nội dung Action: Gọi BorrowRecordDAO.updateStatusToReturned(conn, borrowRecordId) — Cập nhật status = 'returned', returnedAt = NOW(). (Phạt quá hạn, nếu có, đã được OverdueProcessor xử lý).
Nối tới: Mũi tên đi tới [System Action Box 13.1].

[System Action Box 13.1]
Actor: LMS System
Loại: System Action Box
Tên Action: Check Parent Book Status
Nội dung Action: Gọi BookDAO.findByIdForUpdate(conn, bookId) để kiểm tra trạng thái Đầu sách gốc (parent book).
Nối tới: Mũi tên đi tới [Decision Node 13.2].

[Decision Node 13.2]
Actor: LMS System
Loại: Decision Node
Tên Action: Evaluate Parent Book Availability
Nội dung Action: Đánh giá xem Đầu sách có đang ở trạng thái 'unavailable' (ngưng phục vụ) hay không.
Nối tới:
Nhánh [Parent Book Status == 'unavailable']: rẽ tới [System Action Box 13.3].
Nhánh [Parent Book Status == 'active']: rẽ tới [System Action Box 14.1].

[System Action Box 13.3]
Actor: LMS System
Loại: System Action Box
Tên Action: Keep Copy Unavailable & Insert Audit Log
Nội dung Action: Gọi BookCopyDAO.updateStatusToUnavailable(conn, bookCopyId, 'good'). Ghi AuditLog 'CHECK_IN_GOOD_BOOK_UNAVAILABLE'.
Nối tới: Mũi tên đi tới [System Action Box 19.1].

[System Action Box 14.1]
Actor: LMS System
Loại: System Action Box
Tên Action: Update Copy Status To Available
Nội dung Action: Gọi BookCopyDAO.updateStatusToAvailable(conn, bookCopyId) — Chuyển trạng thái bản sao sách về 'available'.
Nối tới: Mũi tên đi tới [System Action Box 15.1].

====================================================================
ĐIỀU PHỐI HÀNG CHỜ (QUEUE ROUTING) — FR-39
====================================================================

[System Action Box 15.1]
Actor: LMS System
Loại: System Action Box
Tên Action: Query Next User In Reservation Queue
Nội dung Action: Gọi ReservationDAO.findNextInQueue(conn, bookId) tìm đơn đặt trước đầu tiên trong hàng đợi (queuePosition = 1, status = 'pending').
Nối tới: Mũi tên đi tới [Decision Node 16.1].

[Decision Node 16.1]
Actor: LMS System
Loại: Decision Node
Tên Action: Evaluate Queue Existence
Nội dung Action: Đánh giá có người đang chờ đặt trước đầu sách này hay không.
Nối tới:
Nhánh [Has Next In Queue (Có người chờ)]: rẽ tới [System Action Box 17.1].
Nhánh [Queue Empty (Không có ai chờ)]: rẽ tới [System Action Box 18.1].

[System Action Box 17.1]
Actor: LMS System
Loại: System Action Box
Tên Action: Promote Next Reservation To ReadyPickup
Nội dung Action: Thực thi tuần tự trong Transaction:
  (1) Lấy holdDays từ SystemConfigurations (mặc định 3 ngày).
  (2) ReservationDAO.updateToReadyPickupWithoutCopy(conn, nextInQueue.getReservationId(), holdDays) — Chuyển status = 'readypickup', gán hạn giữ sách.
  (3) ReservationDAO.decrementQueuePositions(conn, bookId) — Dịch chuyển hàng chờ (position 2->1, 3->2...).
  (4) UserDAO.insertAuditLog(librarianId, 'CHECK_IN_GOOD_QUEUE', ...).
Nối tới: Mũi tên đi tới [System Action Box 17.2].

[System Action Box 17.2]
Actor: LMS System
Loại: System Action Box
Tên Action: Enqueue Async Reservation Email
Nội dung Action: Đăng ký gửi email bất đồng bộ ngoài Transaction báo độc giả kế tiếp đến nhận sách (triggerQueueNotificationEmailAsync).
Nối tới: Mũi tên đi tới [System Action Box 19.1].

[System Action Box 18.1]
Actor: LMS System
Loại: System Action Box
Tên Action: Return Copy To Inventory (Increment Available Quantity)
Nội dung Action: Hàng chờ trống. Gọi BookDAO.incrementAvailableQuantity(conn, bookId) — Tăng availableQuantity +1. Ghi AuditLog 'CHECK_IN_GOOD'.
Nối tới: Mũi tên đi tới [System Action Box 19.1].

[System Action Box 19.1]
Actor: LMS System
Loại: System Action Box
Tên Action: Commit Transaction
Nội dung Action: Thực thi conn.commit().
Nối tới: Mũi tên đi tới [Manual Action 19.2].

[Manual Action 19.2]
Actor: Librarian
Loại: Manual Action
Tên Action: View Check-In Result Summary
Nội dung Action: Thủ thư xem thông báo kết quả nhận sách trên giao diện:
  - Nếu Good: "Nhận sách thành công! Mã vạch: ... — Tình trạng: Tốt".
  - Nếu Damaged/Lost: "Đã ghi nhận nghi vấn sách Hỏng/Mất. Sự cố đã chuyển sang mục Quản lý sự cố (F13) để xác minh".
Nối tới: Mũi tên đi tới [Final Node 20.1].

[Final Node 20.1]
Actor: LMS System
Loại: Final Node
Tên Action: End Check-In Flow
Nội dung Action: Kết thúc luồng Nhận trả sách tại quầy (UC-19). Hệ thống tự động redirect về trang Desk Dashboard.
Nối tới: Không có.
